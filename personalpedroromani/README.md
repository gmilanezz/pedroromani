# Landing Page - Pedro Romani

Projeto mobile first em HTML, CSS e JavaScript puro.

## Incluído nesta versão

- CTA "Sou mulher" no Hero
- CTA "Sou homem" no Hero
- Rolagem suave para a seção correspondente
- Seção de treinamento feminino com provas sociais em fotos
- Seção de treinamento masculino com provas sociais em fotos
- CTA próprio dentro de cada seção
- Identidade visual roxo + branco
- Menu mobile
- Carrossel simples de resultados
- Benefícios da consultoria
- CTA final para WhatsApp
